Git

  • git init — инициализирует новый Git-репозиторий в текущей папке.
  • git add . — добавляет все изменённые и новые файлы в индекс (staging area).
  • git commit -m "Сообщение" — фиксирует изменения в локальной истории с комментарием.
  • git status — показывает текущее состояние репозитория: какие файлы изменены, какие добавлены, какие не отслеживаются.
  • git branch — отображает список веток; с аргументом создаёт новую ветку.
  • git checkout или git switch — переключается на указанную ветку.
  • git push -u origin main — отправляет локальные коммиты на удалённый репозиторий и связывает ветку.
  • git pull — забирает изменения из удалённого репозитория и объединяет их с локальной веткой.
  • git log — показывает историю коммитов.
